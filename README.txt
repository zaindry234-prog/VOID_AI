VOID AI
Created by Reza The Void

VOID AI is an AI chat web application.

PROJECT FILES:
- package.json
- server.js
- public/index.html
- public/style.css
- public/script.js

INSTALLATION:
1. Install dependencies using npm install.
2. Set OPENAI_API_KEY in environment variables.
3. Start the server using npm start.

IMPORTANT:
Never publish your API key.
